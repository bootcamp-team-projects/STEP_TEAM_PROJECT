# STEP Team Project

Flutter 앱과 웹 관리 화면을 함께 구성한 팀 프로젝트입니다. 저장소에는 앱 화면과 재고·발주·매출 등 업무용 웹 화면의 담당 기능 목록이 포함되어 있습니다.

## Project Scope

### Mobile App

- 메인 및 카테고리 화면
- 로그인 및 회원가입
- 상품 상세 화면
- 구매 화면
- 대리점 검색
- 마이페이지 및 주문 내역

### Web / Operations

- 직원 로그인 및 회원가입
- 입고 및 발주 관리
- 매출 현황
- 결재
- 재고 현황

## My Contribution

저장소 내 담당 기능 메모에 따르면 다음 앱 화면을 담당했습니다.

- 로그인 페이지
- 회원가입 페이지
- 상세 페이지

기능별 담당 범위는 저장소의 [기존 화면별 담당 메모](./readme)를 참고해 주세요.
